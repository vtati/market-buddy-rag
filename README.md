# Market Buddy RAG — Week 2 Demo

A focused, demo-purpose RAG application over real SEC filings, built for
The Gen Academy Week 2 project ("Build Your RAG Application",
Use Case 2: Financial Document Intelligence + BYO framing).

**One-liner:** This app helps retail investors answer questions about a
company's business, risks, and reported financials from its actual SEC
10-K filings in a chat surface, with cited, faithfulness-checked answers
— and an honest "I don't know" when the filings don't contain the answer.

It distills the research core of **Market Buddy** (a separate, private,
production product) into a small public codebase built on the Week 2
code track: **LangChain + LangGraph**.

Status: build in progress — see `docs/` for the framework write-up,
the chunking/rerank comparison, and the 15-question evaluation report.
